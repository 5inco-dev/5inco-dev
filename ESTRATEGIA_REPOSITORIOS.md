# ESTRATÉGIA DE NOMENCLATURA E ORGANIZAÇÃO DE REPOSITÓRIOS
## Branding Técnico para Perfil "Cinco" — Desenvolvimento + Banco de Dados + Scrum Master

---

## 🎯 Princípio de Nomeação

Cada nome de repositório deve:
1. **Identificar o tipo de projeto** (backend, frontend, educacional, etc.)
2. **Reforçar o foco em dados e arquitetura**
3. **Ser memorável e profissional**
4. **Opcionalmente, incluir a marca "Cinco"** quando apropriado

## 💡 Diferenciais Dessa Estratégia

✅ **Reforça identidade Cinco** sem ser repetitivo  
✅ **Demonstra foco em Desenvolvimento + Banco de Dados + Liderança**  
✅ **Remover foco em segurança** (nenhum repositório destaca cybersecurity)  
✅ **Cada repositório conta uma história técnica diferente**  
✅ **Pronto para portfólio, entrevistas e LinkedIn**  
✅ **Badges e tópicos melhoram descoberta via GitHub**
